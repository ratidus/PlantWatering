# PlantWatering

Локальний застосунок класу «будильник-довідник» (**Local-first**) для планування графіка поливу кімнатних рослин із сезонним довідником (25 популярних видів).

## Особливості
- **Повна автономність:** не потребує підключення до мережі Інтернет, серверів чи облікових записів (збереження у локальну БД SQLite).
- **Сезонний розрахунок дат:** `Date_next = Date_last + ceil(BaseInterval * K_season)` з урахуванням літнього (`1.0`), весняно-осіннього (`1.25`) та зимового (`1.5`) коефіцієнтів.
- **Фіксація поливу в 1 клік:** екран «Сьогодні» із сортуванням за статусами «Терміново», «Сьогодні», «Заплановано».
- **Довідник рослин:** пошук за підрядком назви та фільтрація за вимогливістю до освітлення.

## Запуск застосунку
```bash
python3 src/app.py
```

## Запуск модульних тестів
```bash
python3 -m unittest discover -s tests -v
```
